Teoría: Fragmentos de Thymeleaf

1. Origen (El Fragmento)

Definimos el fragmento aquí abajo usando th:fragment="miFragmento":

¡Hola! Soy el contenido del fragmento. Fui diseñado una sola vez.

Usando th:replace

El div contenedor original desaparece y es reemplazado completamente por el div del fragmento.

(Este texto y este div desaparecerán)

Usando th:insert

El fragmento se inserta dentro del div contenedor original. El div original se conserva.

(Este texto desaparecerá, pero el div con borde punteado se queda y envuelve al fragmento)

Usando th:include (Obsoleto en Thymeleaf 3, usa insert en su lugar)

Solo inserta el contenido interno del fragmento dentro del div contenedor.

(Este texto se reemplaza por el texto del fragmento, perdiendo el color rojo del div original del fragmento)
